# QBNex name and logo

The QBNex source code is free software under the GNU General Public License,
version 3 or later (see [NOTICE.txt](NOTICE.txt)). The license covers the code.
It does not cover the name "QBNex" or the QBNex logo. Thirawat Sinlapasomsak
owns both. This page says how you may use them.

## Allowed without asking

- Distributing **unmodified** QBNex releases, built from an official tag with
  the official build scripts, under the name QBNex and with the logo.
- Referring to QBNex by name in articles, books, tutorials, videos, reviews,
  package listings and comparisons.
- Saying that your program was "made with QBNex", "compiled with QBNex" or
  "compatible with QBNex", if that is true.
- Using the name and logo in links to the official project.

## Needs permission

- Distributing a **modified** version of QBNex (a fork, a patched compiler or
  runtime) under the name QBNex or with the logo. A fork must use a name of its
  own that cannot be confused with QBNex, and its own logo. It may say that it
  is "based on QBNex".
- Using "QBNex" or the logo in the name of a product, company, domain name,
  social media account or service.
- Selling merchandise with the name or the logo.
- Any use that suggests the QBNex project endorses or is responsible for your
  product.

Ask through the project's issue tracker:
<https://github.com/thirawat27/QBNex/issues>.

of the project QBNex is based on. QBNex is not affiliated with either.
